오픈채팅 HTTP 신고 (open.kakao.com/c/fraud/report/chatLogs)

  
  
  

    ✅ v59-A D10 — OLKCHATROOM §7 노출 매트릭스 기준 9개. RIGHT · YOUTH_UNSUITABLE 는 어느 OLK 화면에도 없어 서버/UI 양쪽에서 거부, ILLEGAL_FILMING 은 GROUP 계열 방에서만 허용. 괄호 안 "코드N" 은 BLSPAMS 정수 매핑(§6): HTTP 백엔드에도 그대로 적용되는지는 추론.
  

  
  
  
  

    ⚠ 제재 임계 돌파 — 두 축:

    (1) 다계정 fanout — 활성 계정 전부로 같은 chatLog 신고. N명 신고가 심사 큐 임계 올림.

    (2) 같은 저자 메시지 묶음 — 아래 "같은 저자의 다른 메시지도 함께 신고" 체크. 1 요청에 최대 5개 (primary 1 + extra 4). "반복 유해" 가중 신호.

    ❌ KICKMEM 은 호스트 봇만 서버 수락 — 일반 멤버는 -500. 임계에 기여 0 (7차 APK 확인).
  

  

    
⏱ 쓰로틀 — 서버 쪽 봇 감지 회피. 계정 간 간격 조절

      봇 쪽: 아래 버튼 — 실제 발사 안 함. 보낼 바이트 전체(URL·헤더·바디·hex) 를 뽑음.

      앱 쪽: tools/frida/android-openchat-http-capture.js
      — 실제 안드로이드(루팅/Magisk) 또는 BlueStacks (x86_64) + frida-server → 

        frida -U -n com.kakao.talk -l 위 스크립트 → 앱에서 "신고하고 나가기" 1회.

        BlueStacks 세팅 가이드: tools/frida/BLUESTACKS_SETUP.md

      비교: 양쪽 출력 포맷 동일. headers·body·hex 를 쭉 훑어서 다른 바이트 있는지 확인.

      → 바이트 같으면 위조 자체는 성공(= 서버가 심사자료로 조작문 받음), 서버 cross-check 가 원인.

      → 바이트 다르면 그 필드가 결정적.
