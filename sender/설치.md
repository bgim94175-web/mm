# 설치 — 코드 수정 없음

## 1. 파일 풀기
ZIP을 리포의 `sender/` 에 푼다.

## 2. push
```bash
git checkout -b feat/report-console
git add -A
git commit -m "feat: 신고 콘솔"
git push -u origin feat/report-console
```

## 3. Render 새 Web Service
- 같은 리포, 브랜치 `feat/report-console`
- **Root Directory: `sender`**
- Build: `npm i --omit=dev`
- **Start Command: `node src/report-server.mjs`**

기존 봇 서비스는 건드리지 않는다.

## 4. 환경변수
```
SENDER_REPORT_API_KEY=&lt;길게 만든 임의 문자열&gt;
```

## 5. 접속
`https://&lt;서비스&gt;.onrender.com/report`
API 키 → 카카오 로그인 → 인증번호 → `상태` → `호스트`

## 6. 아이폰
Safari 공유 → 홈 화면에 추가.

## 주의
- 무료 플랜은 15분 유휴 시 잠든다
- 재시작하면 로그인 토큰이 날아간다. 다시 로그인
- 12건은 전부 실제 접수다. 희생양 계정으로 시험
- `/report/health` 로 살아있는지 확인 가능
